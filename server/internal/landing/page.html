lossmon

This server measures message loss on the {{.Preset}} Logos Delivery network. Volunteers run lossmon-client, which publishes and receives probe messages and reports them here.

1. Install

{{if .Release -}}

Linux amd64, macOS amd64 and arm64. Installs to ~/.local/bin without sudo.

curl -fsSL https://github.com/logos-messaging/logos-delivery-loss-monitor/releases/download/v{{.Version}}/install.sh | LOSSMON_VERSION={{.Version}} sh

To read the script before running it:

curl -fsSLO https://github.com/logos-messaging/logos-delivery-loss-monitor/releases/download/v{{.Version}}/install.sh
less install.sh
LOSSMON_VERSION={{.Version}} sh install.sh

For a manual install with checksums, see the client README.

{{- else -}}

This server is not a release build, so there is no matching client binary to install. Ask the admin which version to use, or build from source as described in the client README.

{{- end}}

2. Token

Get the token from the admin. Then save it:

mkdir -p ~/.config/lossmon && (umask 077; cat > ~/.config/lossmon/token)

Paste the token, press Enter, then Ctrl-D.

3. Run

{{if not .Location -}}

Replace <location> with one of:{{range .Locations}} {{.}}{{end}}.

{{end -}} 
"$HOME/.local/bin/lossmon-client" \
  --server-url={{or .PublicURL "https://"}} \
  --token-file="$HOME/.config/lossmon/token" \
  --data-dir="$HOME/.local/share/lossmon" \
  --preset={{.Preset}} \
{{if .AllowPreset}}  --allow-preset={{.Preset}} \
{{end}}  --location={{or .Location ""}}

Stop with Ctrl-C. Restarting is safe: the client ID is kept in the data directory.
